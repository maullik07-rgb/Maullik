## Aim

To create a doubly linked list and traverse it forward and backward.

## Test Case

insertEnd(10), insertEnd(20), insertEnd(30)

## Expected Output

Forward: 10 <-> 20 <-> 30 <-> NULL
Backward: 30 <-> 20 <-> 10 <-> NULL

## Complexity

Time: O(n) per insertion and per traversal
Space: O(1) auxiliary space (excluding the n stored nodes)
