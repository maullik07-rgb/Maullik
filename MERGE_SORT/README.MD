## Aim

To sort an array of integers in ascending order using the merge sort algorithm.

## Test Case

```
array = 38 27 43 3 9 82 10
```

## Expected Output

```
3 9 10 27 38 43 82
```

## Complexity

- Time: O(n log n) in best, average and worst case
- Space: O(n) auxiliary space (temporary array used while merging)
