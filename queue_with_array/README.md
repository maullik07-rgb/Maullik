## Aim

To implement a linear queue using an array with enqueue, dequeue and display operations.

## Test Case

```
enqueue(10)
enqueue(20)
enqueue(30)
display()
dequeue()
display()
```

## Expected Output

```
10 20 30
Deleted: 10
20 30
```

## Complexity

- Time: O(1) for enqueue and dequeue, O(n) for display
- Space: O(1) auxiliary space (fixed array of size 5)
