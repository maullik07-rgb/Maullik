## Aim

To implement a singly linked list with insertion at the end, deletion by value and display operations.

## Test Case

```
insert = 10 15 20 25 30 35 40 45
delete = 15
delete = 30
display()
```

## Expected Output

```
Linked list as follows - 
10
20
25
35
40
45
```

## Complexity

- Time: O(n) per insertion at the end, O(n) per deletion, O(n) for display
- Space: O(1) auxiliary space (excluding the n stored nodes)
