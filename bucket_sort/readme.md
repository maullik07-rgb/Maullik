## Aim

To sort an array of floating-point values in the range [0, 1) using the bucket sort algorithm.

## Test Case

```
array = 0.42 0.32 0.23 0.52 0.25 0.47 0.51
```

## Expected Output

```
0.23 0.25 0.32 0.42 0.47 0.51 0.52
```

## Complexity

- Time: O(n) average, O(n²) worst case
- Space: O(n) auxiliary space (buckets)
