## Aim

To find the k smallest elements of an array using the quick select algorithm (partition-based selection).

## Test Case

```
array = 7 2 9 4 1 8 3 6
k = 4
```

## Expected Output

```
k smallest elements -
1 2 3 4
```

## Complexity

- Time: O(n) average, O(n²) worst case
- Space: O(log n) auxiliary space (recursion stack), O(n) in the worst case
