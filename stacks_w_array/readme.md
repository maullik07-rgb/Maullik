## Aim

To implement a stack using an array with push, pop and display operations.

## Test Case

```
push(10)
push(20)
push(30)
display()
pop()
display()
```

## Expected Output

```
30 20 10
Deleted: 30
20 10
```

## Complexity

- Time: O(1) for push and pop, O(n) for display
- Space: O(1) auxiliary space (fixed array of size 5)
